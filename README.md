De que trata el proyecto
Este es un programa de consola que sirve para registrar las solicitudes
que hacen los estudiantes en la oficina de soporte academico. El programa
pide los datos del estudiante, valida que esten bien escritos y le asigna
una prioridad segun el tipo de consulta que tenga matricula, pagos, constancia, etc.
